# Матрица соответствия ТЗ

Статусы: **готово**; **частично** — работает с оговоркой; **нет**.
Колонка «Компонент» указывает, где требование закрывается. Метрики артефакта, загруженного проверенным сервисом,
и протокол их получения приведены в [09-report.md](09-report.md) и [12-final-metrics.md](12-final-metrics.md).

| Требование ТЗ | Компонент | Статус |

| Интерпретируемость: по каким признакам объект отнесён к сигналу | Точные вклады признаков в логит (`scorer.py`), блок «Почему модель так решила» в инсайте | готово |

## Этап 2. Открытый поиск

| Требование ТЗ | Компонент | Статус |
|---|---|---|
| Запрос в свободной форме | `POST /api/searches`, главная страница React | готово |
| Поиск в реальном времени по открытым источникам | Сервис веб-поиска `app/search` (SearXNG по умолчанию, Tavily, Exa, Brave, Yandex, OpenSERP, плагин OpenRouter — [11-search.md](11-search.md)) + открытые коннекторы (`open_sources.py`, `research_apis.py`) | готово: живые прогоны в истории |
| Русскоязычные и зарубежные источники | Общий веб-поиск и специализированные коннекторы: Crossref, arXiv, новости, патенты, гранты, закупки, репозитории и медицинские реестры | готово с ограничениями доступности внешних API и языкового покрытия; точные каналы описаны в [11-search.md](11-search.md) |
| Сбор, обработка, проверка, ранжирование | `app/radar/pipeline.py`: поиск → чтение → кандидаты → признаки и модель → проверка цитат → ТОП | готово |
| Не ограничен датасетом или заданным списком технологий | Кандидаты извлекаются из найденного корпуса; примеры заказчика только для валидации | готово |
| ТОП-15 зарождающихся трендов | `rank_results()`: подтверждённые сигналы по вероятности модели, одна технология — одно место; `rank_candidates()`: финальный список из 15 с разбором статусов, исключённые сохраняют вердикт и причину | готово |
| Исключение зрелых, стандартов, хайпа, шума | Модель + причины исключения; «не технология» — `is_technology_flag`; нерелевантное — проверка LLM | готово |
| Для каждого сигнала: описание, преимущество, кейс-пример, источники, скоринг, объяснение | Страница инсайта | готово |
| Выдача не только на знаниях LLM | Признаки из Crossref и Google News; дословная сверка цитат с прочитанным текстом | готово: происхождение цитат проверяется; истинность утверждений автора — нет |

## Требования к источникам

| Требование ТЗ | Компонент | Статус |
|---|---|---|
| Наименование, ссылка, дата, тип, язык, уровень доверенности | `radar_sources` + вкладка «Источники» | готово |
| Реестр доверенных типов источников | `app/registry/sources.json` (17 типов, 353 международных и локальных домена, многоязычные; международные шаблоны госдоменов) + экран «Реестр источников» | готово |
| Соцсети/блоги/агрегаторы — только как первичный индикатор | `primary_only` в реестре; `supports_signal()` | готово |
| Проверка независимых источников | `supports_signal()` оценивает типы источников и ограничения по реестру | готово; независимость и истинность утверждения не гарантирует одно совпадение цитаты |
| Русское резюме зарубежных материалов с пометкой «авто» | инсайт и выгрузка: пометка «сформировано ИИ», цитаты на языке оригинала | готово |
| Сохранение оригинального названия, ссылки, даты, языка | `radar_sources` | готово |

## Программно-аппаратные требования (п. 3)

| Требование ТЗ | Состояние | Статус |
|---|---|---|
| Python 3.8+ | Python 3.12 | готово |
| **PostgreSQL** для данных и результатов | Compose сохраняет запуски и записи источников в JSONB; локально есть SQLite fallback | частично: хранится извлечённый текст и метаданные, исходные HTTP-байты отдельно не архивируются |
| ML/NLP: scikit-learn / PyTorch / Transformers | Обучение — scikit-learn (`ml/scripts`), рантайм — чистый Python по JSON-модели | готово |
| Разделение парсинга, инференса и интерфейса | `app/radar` (поиск), `app/ml` (признаки и модель), `app/registry`, `frontend/` | готово |
| Docker | `docker compose up --build`: PostgreSQL + API + собранный React | готово |
| UI: React + FastAPI | `frontend/` (React 19 + TypeScript) + FastAPI | готово |
| **Модель из разрешённого списка** | Настройка радара в `.env`; шаблон задаёт `openai/gpt-5.6-luna`, дополнительная роль Research и провайдер веб-поиска имеют отдельные настройки. Локально доступен OpenAI-compatible сервер | Настраивается через `.env`; названия моделей не показываются в UI |
| Работа без внешнего LLM API | `RADAR_PROVIDER=local`: LLM-поиск и извлечение признаков идут на локальный сервер; открытые коннекторы и веб-поиск всё равно требуют интернет | Доступно для Ollama/vLLM/SGLang/LM Studio; качество зависит от выбранной модели |
| Интерпретируемость | JSON-артефакт логистической регрессии, вклады 46 входных признаков в карточке кандидата | готово для действующего артефакта |
| Время выполнения | Облачный профиль целится в 18 минут, предельная настройка — 20 минут | Ограничено `RADAR_DEADLINE_SECONDS`; доступность внешних источников не гарантируется |

## Критерии оценки (п. 8) — как закрываем

| Критерий | Наш ответ |
|---|---|
| Выбор алгоритма подбора источников | Два канала поиска (сервис веб-поиска с выбором провайдера и открытые API), RU/EN, реестр доверия, правило независимого подтверждения |
| Обоснованность методологии классификации | Метка по правилу заказчика (стадия ≤ 4, тренд ≥ 2, 99/100 совпадений); трудные негативы — зрелые «родители»; групповая CV; валидация на примерах заказчика с парными негативами |
| Качество и структурированность кода | Разделение слоёв, типизация, автоматические pytest-тесты, ruff, TypeScript |
| Успешность развёртывания по инструкции | `docker compose up --build`, проверено |
| Качество ETL и отказоустойчивость парсеров | Ограниченные повторы, rate-limit cooling, circuit breakers, кэш и изоляция ошибок. Исходные HTTP-байты страниц не архивируются; подробно — [09-etl.md](09-etl.md) |
| Интерпретируемость | Линейная модель, точные вклады признаков со значениями, причины исключения |
| Фильтрация шума и маркетинга | `is_technology_flag`, `marketing_claim_density`, `press_release_share_12m`, реестр источников |
| Отделение от сформированных трендов | Признаки стадии, массовости, возраста области и внедрений; причины исключения на экране |
| Объективная метрика > 75–80% | F1 0,856 у проверенного артефакта на отложенной проверке (разметка `gpt-5.6-luna` из списка ТЗ) |
| Субъективная метрика жюри | Страница инсайта: кейс, цитаты, источники, объяснение уверенности |
