# Обучение модели сервиса

Сервис использует логистическую регрессию из `app/ml/model/logreg_v1.json`. Она обучена на
1327 размеченных строках из `ml/datasets/model_compare/gpt-5.6-luna/training.csv` и использует
46 показателей, рассчитанных для признаков, используемых моделью.

Модель можно воспроизвести из корня репозитория:

```bash
.venv/bin/python ml/scripts/export_model.py
```

Скрипт сохраняет модель в `app/ml/model/logreg_v1.json` и обновляет карточку в
`ml/reports/model_card.md`. При переобучении сервис начнёт использовать новый артефакт после
перезапуска.

Для онлайн-поиска сборщик формирует только входы действующей модели; метрики и протокол оценки
приведены в [12-final-metrics.md](12-final-metrics.md).
