# Обучение действующей модели

В проверенном 20 октября 2026 года локальном сервисе API сообщает об артефакте логистической регрессии logreg_v1: 46 входов и порог 0,42. Сборщик признаков и рантайм используют один и тот же модуль, а файл модели хранит точный список входов, веса, импутацию, масштабирование и калибровку.

Позитивы и негативы отложенной проверки не входят в обучение. Они используются вместе для итоговых метрик. Данные исходной таблицы организаторов представлены в отложенных позитивных примерах; негативы добавлены командой.

Артефакт обучен на наборе, сформированном с разметкой GPT-5.6 Luna. Текущий локальный .env задаёт DeepSeek V4.1 Flash для извлечения признаков, а работающий API возвращает предупреждение о несовпадении модели разметки и модели, использованной для обучения. Поэтому метрики артефакта нельзя считать измерением качества именно текущей конфигурации признаков до устранения этого несовпадения. Подробности — в [настройке модели](10-model-configuration.md).

## Воспроизведение обучения

Основной экспортированный артефакт строится из подготовленной папки сравнения моделей. Команда ниже пересчитывает логистическую регрессию и метрики; для пересчёта признаков исходных примеров дополнительно запускается подготовка набора.

    .venv/bin/python ml/scripts/enrich_training.py
    .venv/bin/python ml/scripts/export_model.py --data ml/datasets/model_compare/gpt-5.6-luna
    .venv/bin/python ml/scripts/jrc_check.py --cached

Экспорт записывает JSON-модель в app/ml/model/logreg_v1.json и карточку в ml/reports/model_card.md. Команды подготовки данных могут обращаться к внешним источникам и выполняться долго; существующие результаты хранятся в CSV.

Логистическая регрессия использует медианную импутацию, стандартизацию, сбалансированные веса классов, L2-регуляризацию и калибровку Платта. Порог выбирается на out-of-fold предсказаниях обучающих строк, а отложенная выборка применяется для итоговой проверки.
