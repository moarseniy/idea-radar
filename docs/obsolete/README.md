# Архив документации

Файлы в этой папке сохранены для истории решений и не являются спецификацией реализации.

| Файл | Почему перемещён |
|---|---|
| `FEATURE_SPEC.md` | Дублировал и частично расходился с `../05-features.md`; полезные признаки объединены в канонический реестр |
| `HACKATHON_PLAN.md` | Предлагал решение без обучения собственной модели; текущий выбор — логистическая регрессия |
| `IMPLEMENTATION_PLAN.md` | Первоначальный аудит с устаревшими допущениями, оценками сроков и архитектурой |
| `03-plan-14-days.md` | Рассчитан на 14 дней и 3–4 разработчиков; актуальный срок — пять дней и два участника |

При любых расхождениях приоритет имеют документы `../01-architecture.md` — `../06-labeling-protocol.md`, особенно `../05-features.md`.
