# План работ на пять дней

Команда: два участника. Цель — к концу третьего дня иметь интегрированный сквозной сценарий, четвёртый день отдать качеству модели, пятый — стабильности и защите.

## Приоритеты

### P0

- единая схема данных и канонический реестр 63 признаков;
- минимальный silver dataset с реальными позитивами и трудными негативами;
- коллекторы OpenAlex и одного патентного источника;
- воспроизводимый feature pipeline без утечки;
- бинарная логистическая регрессия, метрики и вклады признаков;
- открытый запрос → кандидаты → признаки → фильтрация → ТОП-15;
- карточки источников и причины исключения;
- Docker-запуск и журнал моделей/прогонов.

### P1

- GDELT/медиаряд;
- финансирование и пилоты из проверяемых источников;
- временной holdout и калибровка;
- карточка модели в UI;
- история и воспроизведение сохранённых прогонов.

### P2

- GitHub и иные доменные расширения;
- сложный граф;
- несколько LLM-провайдеров;
- расширенный экспорт и автоматическое self-training.

## MVP-признаки для дня 2

Первая модель не ждёт расчёта всех 63 кандидатов. Реализуются наиболее доступные признаки из [05-features.md](05-features.md):

- `A01–A05`: стадия one-hot;
- `A08`, `A09`, `A10`, `A15`: пилоты, production, поставщики, mass market;
- `B01`, `B02`, `B05`, `B07`: публикации, рост, citation velocity, организации;
- `C01`, `C02`, `C05`, `C06`: семейства, рост, новые и все заявители;
- `D01`, `D02`, `D05`: нормализованные медиа, рост, доля PR — если готов GDELT;
- `F01–F04`: текстовые признаки;
- соответствующие `missing_*`.

Если медиа и патенты не готовы, модель стартует на доступном подмножестве; режим и схема фиксируются в model card. Нельзя подставлять сгенерированные числа.

## Контрольные точки

- конец дня 1: зафиксированы aliases, snapshot date и provenance одного объекта;
- середина дня 2: feature table строится одной командой;
- конец дня 2: baseline метрика и коэффициенты доступны;
- конец дня 3: UI показывает вероятность, 3–5 вкладов и evidence;
- конец дня 4: обработаны главные типы ошибок;
- день 5: чистое развёртывание и репетиция.

## Сокращение объёма

Если сквозного результата нет к концу дня 2, исключаются граф, второй патентный источник, финансирование, self-training и редизайн старого `/lab`. Сохраняются OpenAlex, один патентный источник, текстовые признаки, модель, источники и объяснение.

## Критерий готовности

Система принимает неизвестный запрос, находит кандидатов за пределами Excel, рассчитывает признаки из источников, применяет версионированную логистическую регрессию, обоснованно исключает зрелые/неподтверждённые объекты и показывает для итоговых сигналов значения признаков, вклады и источники. Метрики воспроизводятся одной командой на замороженном split.
