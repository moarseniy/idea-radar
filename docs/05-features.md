# Признаки действующей модели

Логистическая регрессия `app/ml/model/logreg_v1.json` принимает ровно **46 числовых признаков**.
Этот документ перечисляет только входы активного артефакта. Точный машинный список и порядок
находятся в JSON-модели; значения собирает `app/ml/features/extract.py` при обучении и оценке.

Значения опираются на доступные датированные документы и структурированные источники. Счётчики
могут преобразовываться логарифмом, категориальные стадии — индикаторами. Отсутствие свидетельства
и измеренный ноль не тождественны; пропуски обрабатываются медианной импутацией.

## Интерпретация и границы

Скоринговый артефакт содержит собственные веса, средние, масштабы и медианы. Линейная модель
рассчитывает вклад каждого входа в логит; положительный или отрицательный вклад описывает связь
с меткой в обучающих данных, но не причинное влияние технологии.

Патентные документы могут появляться в результатах и годовой диаграмме, однако патентных входов
в текущем наборе модели нет. Реестр источников и проверка цитат выполняют самостоятельные задачи
и не заменяются признаками скоринга.

Доступность и полнота признаков зависят от найденных материалов, даты среза, ограничений API и
качества извлечения. Точный список фактических входов берётся из артефакта модели, а не из
списка всех полей, которые экстрактор способен рассчитать.
