## Рендеринг

Локально, без отправки исходников на внешний сервер:

```bash
brew install plantuml          # или: apt-get install plantuml
plantuml -tpng docs/diagrams/*.puml
plantuml -tsvg docs/diagrams/*.puml   # для презентации
```

Рендеры можно сохранить рядом с `.puml` для презентации. Исходные PlantUML-файлы остаются
источником схем; экспортированные изображения не поддерживаются автоматически при изменении кода.
