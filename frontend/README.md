# IDEA — интерфейс технологического радара (React)

Vite + React 19 + TypeScript. Сборка кладётся в `app/static/app/`, FastAPI отдаёт её на `/`
и на маршруты клиента (`/runs/:id`, `/signals/:id`, `/stats`, `/registry`, `/catalog`, `/method`).
Если сборки нет, на `/` открывается прежняя статическая страница (она же — `/legacy`).

```bash
cd frontend
npm ci
npm run dev      # http://localhost:5173, /api проксируется на API_URL (по умолчанию 127.0.0.1:8091)
npm run build    # проверка типов + сборка в ../app/static/app
```

В Docker интерфейс собирается отдельной стадией (см. `Dockerfile`), Node на сервере не нужен.

| Экран | Что показывает (ТЗ) |
|---|---|
| Обзор сигналов | Запрос в свободной форме, дата оценки, история исследований |
| Исследование | Этапы и счётчики: источники, обработанные документы, кандидаты (клик — полный список), сигналы и число с уверенностью > 75%; вкладки ТОП, все кандидаты, исключённые с причинами, источники, статистика |
| Инсайт | Описание, «почему сейчас», ранняя стадия, преимущество, кейс, цитаты; уверенность модели с порогом и вклады признаков; проверка источников и ограничения |
| Статистика | Метрики модели на валидации и сводка по всем исследованиям |
| Реестр источников | Типы, уровни доверия, роль в подтверждении, домены |
| Каталог, Методология | 100 примеров заказчика; как работает радар |
