Подготовка описана в [документе об обучении](../../docs/07-training.md), метрики — в [отчёте](../../docs/12-final-metrics.md). Текущая конфигурация извлечения признаков и артефакт скоринга могут не совпадать; это видно в /api/radar/config.

Обычный поиск не меняет CSV и не переобучает модель. Для применения нового набора нужно явно пересчитать артефакт и перезапустить сервис.
