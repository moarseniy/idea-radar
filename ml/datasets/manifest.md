## Переход на автоматическую разметку

- **2026-09-23.** У команды нет аннотаторов, двойная ручная разметка отменена.
  Замещающая конструкция (`ml/scripts/autolabel.py`, docs/02-methodology.md §5.4):
  модель не выносит суждение о перспективности, а извлекает из собранных документов
  стадию и тренд с цитатой под каждым выводом; метку назначает правило заказчика
  `стадия ≤ 4 и тренд ≥ 2`. Два независимых прохода разными моделями, расхождения
  в обучение не идут.

  Качество разметчика измеряется прогоном по 100 золотым записям вслепую — человеческая
  разметка для этого уже есть, дополнительных человеко-часов не требуется.

  Не измеряется этим способом: ошибка на зрелых технологиях (в золоте нет стадии 5).
  Закрывается структурными негативами, где метка не требует суждения.

  Разметка идёт через OpenRouter. ТЗ п.3.1 допускает внешние сервисы только по
  согласованию, поэтому путь разведён: OpenRouter — инструмент сборки обучающей выборки,
  рантайм сервиса остаётся на модели из разрешённого списка. Это видно в карточке модели.

## Проверка признаков зрелости на золоте

- **2026-09-24.** Для 100 золотых записей сгенерированы канонические поисковые термины
  (2–4 слова), затем прогнана структурная проверка зрелости. Результат:
  early 62%, unverified 18%, mature 20%.

  Правило «термин в литературе 15+ лет → зрелая технология» ложно отсекло 15 из 100
  записей методологов: нейроморфные процессоры, роевая робототехника, оптические нейросети,
  ловкие роботизированные кисти, криогенные вычисления, вычисления в сенсоре. **Откачено.**

  Вывод для методологии: у заказчика слабый сигнал — это новое движение (раунд, новое
  поколение продукта, первые пилоты) в том числе в старой научной области. Рубрика
  «стадия + тренд» измеряет стадию внедрения, а научные базы — возраст идеи. Проверка
  зрелости только по научным базам измеряет не ту ось.

  Второй вывод: 18% золота не имеют публикаций по точному термину («tool poisoning defense»).
  Правило «ноль публикаций → не принимать» отбрасывает самые ранние сигналы.

  Правило «статья в Википедии старше 7 лет» ложно отсекает 5% золота (robot app store,
  swarm robotics, virtual metrology, optical neural network, cryogenic computing), но ловит
  очевидно зрелое, что предлагает модель (FHE, differential privacy, DSSC, AUV). Оставлено.
