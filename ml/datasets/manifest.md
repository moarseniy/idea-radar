# Текущая сводка наборов

Загруженный проверенным API артефакт logreg_v1 использует следующий основной набор:

| Назначение | Файл | Строки |
|---|---|---:|
| Обучение: примеры с извлечёнными признаками | model_compare/gpt-5.6-luna/training.csv | 1327 |
| Позитивная часть отложенной проверки | model_compare/gpt-5.6-luna/gold.csv | 98 |
| Негативная часть отложенной проверки | model_compare/gpt-5.6-luna/validation.csv | 89 |
| Независимая проверка JRC 2021 | external/jrc2021_features.csv | 182 |

В обучении 390 позитивов и 937 негативов. Отложенная выборка состоит из 98 позитивов и 89 негативов и не входит в обучение.

Подготовка и ограничения описаны в [документе об обучении](../../docs/07-training.md), метрики — в [отчёте](../../docs/12-final-metrics.md).
