# Отчёты действующей модели

- [model_card.md](model_card.md) — параметры обученного артефакта и его метрики.
- [jrc2021_check.json](jrc2021_check.json) — результаты внешней проверки на каталоге JRC 2021; для текущего API используется результат раздела v1.
- [model_compare.json](model_compare.json) — техническое сравнение конфигураций извлечения признаков; не является отчётом о работе текущего API.

Итоговый протокол и оговорки: [docs/12-final-metrics.md](../../docs/12-final-metrics.md).
